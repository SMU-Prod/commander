# Onda 59 — Listas e a ação no aviso Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** estrear `BarraFerramentas` nas listas (Diário, Financeiro,
Ocorrências) e dar ao aviso a borda de severidade e a ação nomeada —
executando as linhas da **imagem 1** (chips com contagem + ação na barra) e
da **imagem 6** (Alert Priority Queue) do catálogo `docs/DESIGN-SYSTEM.md`.

**Architecture:** RSC; `BarraFerramentas` é layout puro em
`web/components/ui/` compondo os `Chip` existentes; a ação nomeada do aviso
entra como campo novo `acao` na interface `Notificacao`, preenchido pelos
construtores em `lib/consultas.ts` — a apresentação não inventa verbo.

**Tech Stack:** Next.js 16, Tailwind v4 (tokens), Vitest, Playwright.

## Global Constraints

- Escala `11·12·14·16·20·26·34`; base 8; raio por token; sem cor literal
  nova (catraca por arquivo — arquivo que zerar baixa o teto junto).
- Máximo **2 dourados por tela**: nas listas, a ação principal da barra é
  UM deles; o chip de filtro ativo é o outro. Nada mais.
- Número em `font-mono-instr tabular-nums`; alvo ≥44px; estado é cor E
  palavra; vermelho só crítico.
- **Não regredir a folga da safe-area** (`web/e2e/sem-saida.spec.ts`).
- Verificação por tarefa: `npx tsc --noEmit && npm test && npm run lint`.
  Build na última. Commits em português.

## Fatos do código

- `Chip`/`ChipLinha` (`components/ui/chip.tsx`): `href`, `ativo`, nível
  `primario` = dourado cheio quando ativo. Já usados nas três listas.
- Diário (`app/(app)/diario/page.tsx`): chips de filtro em `ChipLinha`
  (linha 116) e o botão dourado "+ Registrar" SOLTO no cabeçalho (linha 87)
  — é ele que muda de casa.
- Financeiro/lançamentos: `FinanceiroNav` (sub-navegação — NÃO mexer nesta
  onda) + chips de filtro + categoria.
- Ocorrências (`app/(app)/barco/ocorrencias/page.tsx`): chips de
  estado+setor via `comFiltro`.
- `Notificacao` (`lib/domain/notificacoes.ts:90`): tem `href`, `nivel`,
  `grupo` — **não tem rótulo de ação**. Os construtores moram em
  `lib/consultas.ts` (`carregarNotificacoes`).
- `CartaoNotificacao` (`app/(app)/notificacoes/page.tsx:54`): link genérico,
  chip de nível à direita, SEM borda lateral de severidade.
- Varredura: régua de sobreposição mede scroll 0 e acusa a casca fixa
  (bottom-nav/FAB) sobre conteúdo em 25+ telas — ruído sistemático conhecido.

**Interfaces:**

- [ ] **Passo 1: teste primeiro** (`renderToStaticMarkup`, padrão de
  `abas.test.ts`): com `acao`, renderiza UM link com `bg-accent` e o rótulo;
  sem `acao`, nenhum `bg-accent`; os filtros aparecem; altura mínima do
  botão ≥44px (`min-h-11` presente). Ver falhar.

- [ ] **Passo 2: implementar**

```tsx
import Link from "next/link"
import { ChipLinha } from "./chip"
import { Icone } from "../icone"
import type { ReactNode } from "react"

/**
 * ONDA 59 — a barra de uma tela de LISTA (spec de arquitetura §2.2;
 * referência: imagem 1 do docs/DESIGN-SYSTEM.md — chips à esquerda, ação
 * à direita, UMA altura). Antes dela, cada lista punha o botão de criar
 * num canto diferente e a varredura de 15/08 achou a mesma pílula de
 * filtro em 12 telas com 6 alturas. A ação de criar MORA aqui — não
 * flutuando, não no cabeçalho.
 */
export function BarraFerramentas({ filtros, acao, className = "" }: {
  filtros: ReactNode
  acao?: { href: string; rotulo: string }
  className?: string
}) {
  return (
    <div className={`flex items-center gap-2 ${className}`}>
      {/* min-w-0 pro scroll dos chips não empurrar a ação pra fora */}
      <ChipLinha className="min-w-0 flex-1">{filtros}</ChipLinha>
      {acao && (
        <Link
          href={acao.href}
          className="flex min-h-11 shrink-0 items-center gap-1 rounded-[var(--raio-pilula)] bg-accent px-4 text-sm font-semibold text-acao-texto"
        >
          <Icone nome="mais" className="size-4" aria-hidden />
          {acao.rotulo}
        </Link>
      )}
    </div>
  )
}
```

  Confira a API real do `ChipLinha` antes (se ele não aceitar `className`,
  ajuste lá — é uma linha — em vez de duplicar o wrapper).

- [ ] **Passo 3: verificar e commitar** —
  `feat(ui): BarraFerramentas — filtros e a acao de criar numa altura so`.

## Tarefa 4 — O aviso ganha borda de severidade e ação nomeada

**Files:**
- Modify: `web/lib/domain/notificacoes.ts` (campo `acao: string` em
  `Notificacao`)
- Modify: `web/lib/consultas.ts` (cada construtor preenche `acao`)
- Modify: `web/app/(app)/notificacoes/page.tsx` (`CartaoNotificacao`)
- Test: estender `web/lib/domain/notificacoes.test.ts`

- [ ] **Passo 1: o domínio.** `Notificacao` ganha `acao: string` —
  obrigatório, não opcional: aviso sem ação nomeada é o defeito que o spec
  §3.2 aponta (*"aviso que não se resolve pelo aviso é aviso que se lê
  duas vezes"*). Cada construtor em `lib/consultas.ts` nomeia o verbo do
  seu tipo, apontando pro `href` que JÁ existe: item vencido →
  `"Registrar manutenção"`; documento → `"Renovar documento"`; ocorrência →
  `"Ver ocorrência"`; compromisso → `"Abrir agenda"`; financeiro →
  `"Ver lançamento"`; marketplace → o verbo da demanda. Leia os
  construtores um a um — o verbo certo é o da TELA DE DESTINO, não um
  genérico. Teste: todo construtor devolve `acao` não vazia.

- [ ] **Passo 2: o cartão.** `CartaoNotificacao` (imagem 6 do catálogo):
  - **borda lateral de severidade**: `border-l-2` com a cor do nível
    (crítica `border-l-crit`, importante `border-l-warn`, informativa
    fica na `border-line`) — some com o preenchimento `bg-crit/[0.06]`
    atual se ficar redundante; a borda é o sinal, o fundo era o paliativo;
  - **a ação vira texto visível** no rodapé do cartão (`n.acao` em
    `text-sm font-medium` com chevron), no lugar do papel de "link mudo"
    — o cartão inteiro continua sendo o link (um alvo só, ≥44px).
  - o chip de nível à direita FICA (estado é palavra).

- [ ] **Passo 3: o vazio diz quando verificou.** No `EstadoVazio` de
  "Nenhuma pendência", a descrição diz que a verificação é **desta
  abertura da tela** (a lista é calculada ao vivo em `carregarNotificacoes`
  — "verificado agora" é a verdade literal): *"Verificado agora. Críticas e
  importantes chegam aqui e no aparelho."*

- [ ] **Passo 4: verificar e commitar** — tsc/test/lint + a tela com as
  três severidades no navegador —
  `feat(avisos): todo aviso traz a acao, e a severidade e uma borda`.
